# Source images

Original, unmodified images archived from https://www.jintongyang.com/ on 2026-11-20.
File names are the item ids used on that site (`/Product/view/id/<id>`, `/Cases/view/id/<id>`).

`npm run images` derives the web-ready files in `public/images` from these originals
(see `scripts/prepare-images.mjs`). Do not edit files in `public/images` by hand.
